# Glossary

- **CAN**: Computer Association Nepal. The organization overseeing this scholarship portal.
- **JWT**: JSON Web Token. A cryptographic token used to verify the identity of the user on the backend without maintaining server-side session state.
- **RBAC**: Role-Based Access Control. The system by which API access is restricted based on the user's role (e.g., student vs. institution).
- **ESM**: ECMAScript Modules. The modern JavaScript module system (`import` / `export`) used in the backend, replacing the older CommonJS (`require()`).
- **StudentSnapshot**: A frozen copy of a student's personal and academic data taken at the exact moment they submit a scholarship application.
- **Multer**: A Node.js middleware used for handling `multipart/form-data`, primarily for uploading PDF and Image documents to the server.
- **Hydration**: The process in `AuthContext.jsx` where the React app reads `localStorage` upon initially loading to restore the user's logged-in session.
